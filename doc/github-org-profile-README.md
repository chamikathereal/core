## Packages

| Package | Description |
| :--- | :--- |
| [`@deneb-ui/ui`](https://www.npmjs.com/package/@deneb-ui/ui) | 40+ React components — Navbar, Hero, ProductGrid, CartDrawer, and more |
| [`@deneb-ui/cli`](https://www.npmjs.com/package/@deneb-ui/cli) | Convert, validate, and package Fivora-ready templates |
| [`@deneb-ui/create-template`](https://www.npmjs.com/package/@deneb-ui/create-template) | Scaffold a new storefront in one command |

## Quick start

```bash
npm create @deneb-ui/template my-store
# or convert an existing Next.js app:
npx @deneb-ui/cli init
```
